## F1 — כותרות ביניים חוצות-טורים חופפות גוף (919 זוגות ב-154 עמ')

### RC-F1a — עוגן הפס ויישור הצל (dp-planner.js/pushH3BandRecords)

**הפגם:** רשומות הפס הוצבו בטור 0 בגובה המילוי שלו, וה"צל" (רזרבציה) בטור
המשני הוצב בגובה המילוי **של אותו טור** — לא בעוגן הפס. הפרש הטורים שנותר
אחרי איזון פלחי-הזנב (גרנולריות שורה, 13–26px נמדדו) גרם לגוף הטור המשני
להמשיך מתחת לצל **בתוך טווח ה-y של הפס** — שמרונדר חוצה-טורים ברוחב מלא.
הוכחה (HTML p143, מודל): פס c0.9 ב-y=312.16–334.12 מול שורת גוף c1.52
ב-y=316.68 — חפיפה 17.44px במודל עצמו (לא בכותב ה-PDF).

**חוזה המקור (הוכח מהפורט legacy-imud-flow):** `curY = blockBottom()` —
max סמני שני הטורים (§2005); `layoutStack` מציב את הפס ב-`seg.y + 8`;
`openBlock` מתחת לפס. כלומר: **עוגן הפס = התחתית המשותפת (הטור הגבוה)
+ פער-הבלוק + ריפוד הפס; שני הטורים מפנים את אותו טווח-y והתוכן ממשיך
באותו y בשניהם.**

**התיקון:** `pushH3BandRecords` מחשב `base = max(planningUsedHeight)` מעל
כל הטורים; רשומת הפס הראשונה והצל הראשון נושאים `gapBeforePx = blockGap +
H3_TOP_PAD + (base − מילוי הטור)` — הצל מזמין את ההפרש עד העוגן (גיאומטריה
קבועה, `isFixedBandLine`). בדיקת המקום מנכה את פער הבלוק של הפס
(`cap − usedMax − bandGap ≥ roomNeeded`) — כמו `curY` של המקור שכולל
מרווח הפסקה עוקב.

### RC-F2a — שני מקורות גיאומטריה לתיבת הכותרת (ornament-plan.js)

**הפגם:** ההקרנה (materialize) מציבה את שורות הפס ב-bandTopPx המכויל
(Iteration-003) ושורה עם yPx נעוצה בו; חישוב העיטור השתמש ב-contentBox.top
בלבד ⇒ תיבת הכותרת של העיטור נפלה ~60px מתחת לכותרת בפועל (נמדד: עיטור
y=433px מול כותרת בעוגן 344.05px) — עיטור ה-h2-bottom נחת בתוך הגוף.

**התיקון:** אותו מסלול-y כמו materialize (bandTopPx → topPad → yPx לכל שורה);
תיבת הכותרת = תיבת הטקסט בלבד (בלי ריפודי ההזמנה); ההכלה — העיטור חי בתוך
ההזמנה שנקבעה בפריסה (h2OrnPadBottom / spanning.orn.bottomPx — מקור אחד
לשלושת נתיבי ה-H2: פס-ממוקם-עוגן, פס FWD-1, וטור); בפס-ממוקם-עוגן הזרימה
קבועה — שם אין מקום וההזמנה נדחית בתיעוד; שולי דיו ≥2px לעיטור העליון
(הגליפים מבצבצים מעל תיבת השורה — נמדד p634).

### RC-F3a — colUsed בגבהים גולמיים + עוגן ללא הפס + קיבולת בלי תקציב

**הפגם (שלושה חלקים):** (1) colUsed ספר גבהים גולמיים — בלי aqStretch (המתיחה

עיטור ב-748px מול תוכן עד 794); (3) הקיבולת לא ניכתה את תקציב ההערות (U-8 —
המרזב חוצה-רוחב; נמדד p260: עיטור בתוך המרזב מול הערות עד y=773).

**התיקון:** colUsed = סמנטיקת רינדור (balancing.usedHeight: גובה×aqStretch
+ פער); הקיבולת = colCapacityOf (מקור יחיד — פס+תקציב+שמורות); העוגן =
flowTop מתחת לפס.
